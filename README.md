### Sobre

Interface web desenvolvida em **React** para o sistema de gestão de transporte escolar da DECEL, com autenticação via **JWT** e integração com a API REST via **Axios**.

Projeto Integrador I — Bacharelado em Ciência da Computação · UNOESTE

---

### Funcionalidades

- Autenticação com login e controle de sessão via JWT
- Gestão de alunos, escolas, rotas e pontos de embarque
- Controle de inscrições, monitores, motoristas e veículos
- Interface integrada à API REST do backend

---

### Como rodar

```bash
git clone https://github.com/paulomcfm/ProjetoDECEL-frontend
cd ProjetoDECEL-frontend
npm install
npm start
```

> O backend deve estar rodando antes de iniciar o frontend.
